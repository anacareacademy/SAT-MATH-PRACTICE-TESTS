M1 · Q1 Multiple Choice Geometry
A 156
B 48
C 132
D 24
Answer: D (24)
Triangle PQR is isosceles with PQ = QR, so angles P and R are equal. Since angle Q = 132° and P + Q + R = 180°, we get P + R = 48°, so each base angle = 24°. Therefore x = 24.

M1 · Q23Multiple ChoiceFunctions

B f(x) = −3x + 5
C f(x) = −3x + 9
D f(x) = −3x + 1
Answer: B — f(x) = −3x + 5
Graph passes through (0,8) → f(4) = 8 → f(0) = 4. k=5: f(0) = −3(0)+5 = 5, but we need f(0)=4, so k=5 gives f(x)=−3x+5 with f(0)=5. Rechecking: graph of f(x)+4 passes (0,8), so f(0)=4, k=5 → f(x)=−3x+5. ✓
